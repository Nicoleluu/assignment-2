# Assignment 2 — Website Modification

## Aesthetic Style

For this project, I transformed the original template into a warmer, softer, and more playful interface.

The overall aesthetic focuses on comfort, lightness, and small moments of discovery. I wanted the website to feel structured but not rigid.

Key qualities:
- Warm
- Soft
- Playful
- Minimal
- Organic

## Inspiration

My inspiration came from:
- Scrapbook compositions
- Printed materials
- Soft interior spaces


## Design Decisions

### Color Palette

I used warm neutral colors like cream, beige, and brown to create a calm and inviting atmosphere.

The softer palette helps reduce harsh contrast and makes the site feel more cohesive.

### Typography

I adjusted the typography to create clearer hierarchy and a softer rhythm across the page.

### Layout

I modified the original template by:

- Enlarging the tile system
- Creating more breathing room
- Improving spacing between modules
- Making the structure feel less compressed


## Context-Based Details

One important change I made was adding small visual elements according to the content of each section.

Instead of making every tile look identical, I introduced small details that respond to the context, making each section feel more specific and intentional.

These small additions create more personality and help users connect with the content.

## Interactive Components

I modified several interactive elements:

- Draggable text boxes
- Clickable scrolling text
- User-generated input sections
- Animated marquee text
